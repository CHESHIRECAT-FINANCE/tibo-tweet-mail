启用自动订阅

配置好一次，之后由 GitHub 云端检查，电脑可以关机。

这里包含邮箱授权码。只粘贴到自己的 GitHub Secret，勿上传到代码仓库或公开分享。

此密钥保护云端待发内容和记录。首次启用时保存；修改订阅时沿用原密钥，不能直接替换。

  1. 复制开源项目到自己的 GitHub，进入仓库的 Settings → Secrets and variables → Actions。
  2. 添加两个 Repository secrets：INFO_RELAY_CONFIG 和 INFO_RELAY_STATE_KEY，分别粘贴上面生成的配置和密钥。
  3. 打开 Actions → InfoRelay subscriptions → Run workflow。先选 diagnose 检查，再选 test-email 发测试邮件。
  4. 收到测试邮件后，在 Actions 的 Variables 页添加 INFO_RELAY_ENABLED，值为 true。手动运行一次 run 建立记录，之后自动检查。

新订阅每 10 分钟请求检查一次，GitHub 可能延迟调度。首次 Fork 后可能需要在 Actions 页面启用工作流。了解运行限制
